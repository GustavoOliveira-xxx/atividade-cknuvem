Arquitetura

Do navegador até a máquina virtual

O caminho que uma requisição percorre quando alguém digita o IP público da instância.

  1. 01Navegadorhttp://IP-PÚBLICO
  2. 02InternetIPv4 público da AWS
  3. 03Security Grouplibera 80 (HTTP) e 22 (SSH)
  4. 04Instância EC2Ubuntu Server
  5. 05Apacheentrega /var/www/html

Etapas realizadas

O que fizemos, passo a passo

  1. Acessar o EC2

    No Console da AWS, pesquisamos por EC2, o serviço que cria máquinas virtuais (instâncias).

  2. Executar instância

    Launch instance, com o nome Servidor-Web-Equipe01.

  3. Escolher a AMI

    Imagem Ubuntu Server: o modelo com o sistema operacional da VM.

  4. Tipo da instância

    Configuração de pequeno porte, elegível ao plano gratuito.

  5. Par de chaves

    Create new key pair → chave-equipe01, download do arquivo .pem.

  6. Security Group

    Porta 22 (SSH) restrita ao nosso IP e porta 80 (HTTP) liberada.

  7. Criar a máquina

    Revisão e Launch instance, aguardando o estado Running.

  8. IP público

    Anotamos o Public IPv4 address: é por ele que o site é acessado.

  1. Acessar a máquina

    Botão Connect → EC2 Instance Connect, abrindo o terminal Linux no navegador.

  2. Instalar o Apache

    Atualização dos pacotes e instalação do servidor web.

    sudo apt update
sudo apt install apache2 -y
sudo systemctl status apache2

  3. Testar no navegador

    Acesso a http://IP-PÚBLICO e exibição da página padrão do Apache.

  4. Publicar nossa página

    Criação dos arquivos desta página na pasta do Apache.

    sudo nano /var/www/html/index.html
sudo nano /var/www/html/style.css
sudo nano /var/www/html/script.js

Conceitos na prática

      
O que cada peça representa

      

        
Máquina virtual
Um computador completo, criado por software dentro da infraestrutura física da AWS.

        
Instância
O nome que a AWS dá a cada máquina virtual em execução no EC2.

        
AMI
Imagem-modelo com o sistema operacional instalado na criação da instância.

        
IP público
Endereço que torna a instância alcançável por qualquer navegador na internet.

        
SSH & chave .pem
Acesso remoto seguro ao terminal, autenticado por par de chaves em vez de senha.

        
Security Group
Firewall virtual: só as portas liberadas (22 e 80) aceitam conexões.
